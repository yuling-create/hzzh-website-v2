# 汇众智慧官网 V5 · 自适应原生 Banner 版

这版不再使用“整张 Banner 图片铺满页面”的做法，改成 Vue + CSS 原生响应式 Banner：

- 首页：左侧品牌文案 + 右侧系统化产品组合视觉
- 产品图片使用项目内原始透明 PNG，不会因为整图拉伸而发糊
- 背景、网格、科技线条、玻璃面板全部用 CSS 绘制
- PC / 平板 / 手机按断点自动重新排版
- 内页 Banner 统一使用同一套蓝白视觉语言，但根据页面内容更换对应产品 / 企业图片
- 原有页面内容、产品资料、新闻、行业应用及图片资源均保留

## 运行

```bash
npm install
npm run dev
```

## 打包

```bash
npm run build
```
